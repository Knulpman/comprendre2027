# Comprendre 2027

Guide citoyen indépendant sur l'élection présidentielle française de 2027 : https://comprendre2027.lucaschatel.me

- `source/guide.html` : la page source (identique à la version publiée sur Claude, photos intégrées).
- `build.py` : génère `index.html` et `photos/` à partir de la source (`python3 build.py`).
- Chaque push sur `main` est déployé automatiquement par Vercel.

Éditeur : Lucas Chatel, à titre personnel. Préparé avec l'aide de Claude (Anthropic) ; chaque information est sourcée.
